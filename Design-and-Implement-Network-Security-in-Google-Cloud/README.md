# Design and Implement Network Security in Google Cloud: Challenge Lab (GSP399)

Solusi dan automated bash script untuk menyelesaikan **Design and Implement Network Security in Google Cloud: Challenge Lab (GSP399)** di Google Cloud Skills Boost / Google Cloud Arcade.

## Cara Menjalankan di Cloud Shell

Jalankan perintah berikut di Google Cloud Shell:

```bash
curl -LO https://raw.githubusercontent.com/loehoedP/Google-Arcade-Guild-2026/main/Design-and-Implement-Network-Security-in-Google-Cloud/GSP399.sh
chmod +x GSP399.sh
./GSP399.sh
```

## Cakupan Task

- **Task 1:** Migrate Legacy VPC Firewall Rules to a Global Policy (`unified-fw-policy`)
- **Task 2:** Remediate Outbound Cloud NAT Resolution (`unified-nat`)
- **Task 3:** Contain Compromised Workload & Enable VPC Flow Logs
